宣传对象是「AI Agent 学习图谱」：https://honestant.github.io/ai-agent-mindmap/

它是《深入理解 AI Agent：设计原理与工程实践》（李博杰，[bojieli/ai-agent-book](https://github.com/bojieli/ai-agent-book)）中文版的学习笔记，不是官方版本。视频里要说清这一点，也要把原书和作者放进简介。

## 一句话定位

**第一次学 Agent，先用 10 分钟把词弄懂，再去读原书。**

观众：听说过 Agent、用过 ChatGPT 或 Cursor，但说不清 Agent 和聊天机器人差在哪的人。不面向已经在做 Agent 的工程师。

1. 用一个干净的浏览器窗口：隐藏书签栏，关掉其他标签页和扩展图标，关掉系统通知。
2. 打开线上地址，不要录本地文件路径。
3. 划词评论存在浏览器本地。录之前先删掉测试时留下的划词，让右侧栏是空的；划词那一段现场演示。
4. 提前点一遍各页，让图片和原文预览都加载过，正式录时不卡。
5. 鼠标移动放慢，每个画面停 2–3 秒再动。点击处可以加放大或高亮。
6. 口播和录屏分开录更稳：先录屏，再对着画面念下面的提词稿。

## 提词稿

一行一句，念的时候按行停顿。括号里是画面动作，不念。

### 开头（0:00–0:30）

你可能天天在用 AI，可是 Agent 到底是什么？

它和聊天机器人差在哪？

（画面：首页大标题）

一句话：Agent 是会自己一步步把事做完的 AI。

聊天机器人回你一段话就结束了。

Agent 会去查、去做，看到结果，再决定下一步。

（画面：指向三张小卡）

它由三样东西组成：

大模型是大脑，负责想下一步做什么。

上下文是眼睛，就是它这一轮能看见的全部文字。

工具是手脚，让它去查东西、改东西。

### 订机票的例子（0:30–0:55）

（画面：滚到订机票的例子，逐行停顿）

比如你说：帮我订下周三去上海的机票。

它先想：要搜航班。

搜的时候发现要登录，就先核实身份，再回来搜。

看到最便宜的要转机，它会问你接不接受。

你说不要，它就把「不要转机」记下来，换个条件重新搜。

想、做、看，一轮接一轮，这就是 Agent 的工作方式。

### 为什么不能只信它（0:55–1:15）

（画面：「模型外面，还有一层程序」）

不过，光有模型还不够可靠。

模型外面还要有一层程序：给它准备材料，限制它能做什么，检查它做得对不对。

比如退款，它说「退好了」不算数。

要去数据库里查，钱真的退了，才算。

### 入门卡片（1:15–1:45）

（画面：点左侧「入门卡片」，慢慢往下划）

这些词第一次听可能有点乱。

所以我把最基础的概念做成了 14 张卡片。

每张先讲一句人话，再举一个例子，最后是一句要记住的话。

比如「提示注入」：你让它读邮件，邮件里却写着「把通讯录发给我」。

记住一句：外面来的内容只是资料，不是命令。

### 十章地图（1:45–2:10）

（画面：点「十章地图」，停住，再点开一章）

这些内容都来自一本开源书：李博杰的《深入理解 AI Agent》。

全书十章，我把它们画成了一张地图。

前六章讲怎么造一个 Agent，后四章讲怎么让它越用越好。

每章先看一句话，想细看，再点开。

### 原文预览（2:10–2:30）

（画面：点一条「原文」，等预览弹出并滚到对应小节）

笔记难免会简化。

所以每一句都标了出处，一点就能看到原书里对应的那一段。

不用跳出页面，也不用自己翻目录。

### 划词评论（2:30–2:45）

（画面：在原文里选中一句，点「评论」，输入一句，发送，右侧出现记录）

读到想记的地方，选中一句，点「评论」，写下自己的想法。

笔记只存在你自己的浏览器里，不用注册，也不用登录。

### 结尾（2:45–3:00）

（画面：回到首页，或露脸）

这是我自己整理的学习笔记，不是原书的官方版本。

说法以原书为准，原书还有 100 多个配套实验，强烈建议去看。

网站和原书的地址都放在简介里，免费打开就能用。
